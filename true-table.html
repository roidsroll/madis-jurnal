Proposisi | Operator Logika | Tabel Kebenaran

Negasi (¬)

Input (A) Output (¬A / NOT A)
T (True / 1) F (False / 0)
F (False / 0) T (True / 1)

Konjungsi (∧)

Input (A) Input (B) Output (A ∧ B / A AND B)
T (True / 1) T (True / 1) T (True / 1)
T (True / 1) F (False / 0) F (False / 0)
F (False / 0) T (True / 1) F (False / 0)
F (False / 0) F (False / 0) F (False / 0)

Disjungsi (∨)

Input (A) Input (B) Output (A ∨ B / A OR B)
T (True / 1) T (True / 1) T (True / 1)
T (True / 1) F (False / 0) T (True / 1)
F (False / 0) T (True / 1) T (True / 1)
F (False / 0) F (False / 0) F (False / 0)

Implikasi (→)

Input (A) Input (B) Output (A → B / IF A THEN B)
T (True / 1) T (True / 1) T (True / 1)
T (True / 1) F (False / 0) F (False / 0)
F (False / 0) T (True / 1) T (True / 1)
F (False / 0) F (False / 0) T (True / 1)

Biimplikasi (↔)

Input (A) Input (B) Output (A ↔ B / A IFF B)
T (True / 1) T (True / 1) T (True / 1)
T (True / 1) F (False / 0) F (False / 0)
F (False / 0) T (True / 1) F (False / 0)
F (False / 0) F (False / 0) T (True / 1)
